### 🧑‍💻 About Me

I am **Alfa (Yahfi)** — a **Cybersecurity Engineering Student** based in Indonesia, focused on the intersection of **offensive web application security, vulnerability assessment, and applied cryptography**.

My current work revolves around hunting high-impact flaws in bug bounty targets, sharpening exploitation mechanics in CTF challenges, and engineering security-first tools — grounded in applied cryptography and cloud infrastructure resilience.

---

### 🎯 Core Focus Areas

| Domain | Specialty & Applied Scope |
| :--- | :--- |
| 🌐 **Web Exploitation** | Hands-on exploitation of **SQLi, XSS, IDOR, Broken Authentication**, SSRF, and business logic flaws across CTF & real-world targets. |
| 🔍 **Bug Bounty Hunting** | Continuous recon & vulnerability hunting on **HackerOne** programs utilizing automated multi-stage asset discovery pipelines. |
| 🔐 **Applied Cryptography** | Secure cryptographic service engineering, symmetric encryption (`AES-256-GCM`), key lifecycle management, and implementation review. |
| ☁️ **Cloud & Distributed Security** | OWASP risk rating methodology, OAuth 2.0 flows, container hardening (`Docker`), and secure microservice architectures. |
